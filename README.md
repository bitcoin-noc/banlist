# banlist

An optional, centralized, and incomplete banlist containing the IP addresses of
possibly malicious entities on the Bitcoin network.

Website: https://bitcoin-noc.github.io/banlist/

## Using the list

The website serves the banlist in these formats:

- https://bitcoin-noc.github.io/banlist/banlist_cli.txt contains `bitcoin-cli setban`
  commands to ban the IP addresses on the list.
- https://bitcoin-noc.github.io/banlist/banlist_gui.txt contains `setban` commands
  for the console tab of the Bitcoin Core GUI.
- https://bitcoin-noc.github.io/banlist/banlist_plain.txt contains only the IP
  addresses and networks, one per line.
- https://bitcoin-noc.github.io/banlist/entities.json contains all entities with
  their networks and metadata, described by
  https://bitcoin-noc.github.io/banlist/schema.json.

**Note: Always check files downloaded from the internet for malicious commands
first before using them. These files are not scripts.**

Networks are banned for one year unless an entity sets a different `bantime_days`.

## Repository layout

```
entities/<slug>.toml      one file per entity (the dataset)
entities/<slug>.ips.txt   optional sidecar with many single addresses for an entity
tags.toml                 the allowed tags and what they mean
contrib/banlist.py        validates the dataset, generates banlists and the website
contrib/templates/        HTML templates, contrib/static/style.css the stylesheet
```

The banlist files and the website are generated by CI on every push to `main`
and are not committed. Pull requests are validated automatically.

## Adding an entity

When adding a new entity, please provide detailed information about the
entity's behavior and why you think the entity is malicious. Add a file
`entities/<slug>.toml`, where `<slug>` is a short lowercase identifier
(`^[a-z0-9][a-z0-9-]*$`) that becomes the URL of the entity's page. Then run
`python contrib/banlist.py validate` (Python 3.11 or newer, no dependencies).

```toml
name = "Unique name"                   # required. Someone searching for the
                                       # entity should be able to find this name.
summary = "One sentence about the entity and why it is listed."  # required
added = 2009-01-03                     # required, date the entity was added
tags = ["tx-spy"]                      # required, may be empty; see tags.toml
bantime_days = 365                     # optional, default 365
removed = 2009-06-01                   # optional, when the entity was taken off the list
removed_reason = "No longer active."   # optional, only with removed
user_agents = ["/Satoshi:0.1.0/"]      # optional
asns = [{ asn = 65536, name = "Example Networks" }]  # optional

description = """
Plain text, required. Blank lines separate paragraphs. Lines starting with
"- " form a bullet list, `backticks` mark code, and bare https:// URLs become
links. No HTML or Markdown.
"""

[[references]]                         # optional, repeat as needed
url = "https://example.com/post"
title = "Title of the linked page"
date = 2009-01-03                      # optional

[[networks]]                           # repeat for each address or range
cidr = "208.67.222.0/24"               # IPv4/IPv6 address or CIDR; host bits must be zero
added = 2009-01-03                     # optional, defaults to the entity's added date
note = "Observed connecting daily."    # optional

[[networks]]
cidr = "208.67.222.222"                # a single host
removed = 2009-02-01                   # optional; retired networks stay as history
                                       # but are not banned
```

For entities with hundreds of single addresses, put them into
`entities/<slug>.ips.txt` instead, one address or network per line (`#` starts
a comment). They are treated as active networks added on the entity's `added`
date.

Prefer listing a whole range only when the whole range is used by the entity.
Banning a range that also contains unrelated hosts bans innocent peers. When in
doubt, list the individual addresses.

Tags describe the entity's behavior and must be defined in `tags.toml`. Reuse
existing tags where possible; add a new one with a one-line description if none
fits.

When an entity changes its addresses, keep the old networks and set `removed`
on them instead of deleting them. When an entity is no longer worth banning, set
`removed` and `removed_reason` on the entity; its page is kept for reference.

## Generating the lists and the website

```
python contrib/banlist.py validate
python contrib/banlist.py banlist OUTDIR
python contrib/banlist.py site OUTDIR
```

See `contrib/README.md` for details.
