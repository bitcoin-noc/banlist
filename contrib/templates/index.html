Using the list

The banlist is available in these formats:

  • $cli_file: bitcoin-cli setban commands
  • $gui_file: setban commands for the console of the Bitcoin Core GUI
  • $plain_file: one IP address or network per line
  • $json_file: all entities with their networks and metadata (JSON Schema)

These files are not scripts. Always check files downloaded from the internet for malicious commands before using them.

Networks are banned for $default_bantime_days days unless an entity specifies a different duration. The list is optional, centralized, and likely incomplete. Entities are added and removed by hand; see the repository for how to contribute.
